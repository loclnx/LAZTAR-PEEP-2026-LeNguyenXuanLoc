## Overview

Day 2 focused on translating Mini-WMS operational needs into a clear dashboard interface. Figma was used to draft and refine the layout before implementation in the application. The design aims to help warehouse staff and managers find important information without having to move between multiple areas.

Because the dashboard may be used on different devices, responsiveness was part of the design process. Content needs to adapt to the available screen width while preserving its information hierarchy and readability.

## Key Focus Areas

### 1. Defining the dashboard's purpose

The dashboard serves as an entry point for understanding warehouse operations. The design therefore prioritizes quickly scannable operational information instead of presenting too much detail at once. Its content is organized around high-level metrics, inventory status, and key warehouse activity.

### 2. Building the UI in Figma

Figma was used to create the interface layout and show how its content areas work together. Designing in the tool made it easier to review information hierarchy, spacing, label clarity, and consistency before moving to implementation.

### 3. Responsive design and usability

- The layout should adapt to both wide and narrow screens.
- Important information should be easy to identify and scan.
- Content areas should have a clear hierarchy and avoid visual overload.
- Navigation and presentation should support frequent tasks in a warehouse setting.

## Lessons Learned

### 1. A dashboard must prioritize information

A useful dashboard is not simply a collection of data on one screen. The order and grouping of information determine whether users can quickly identify what needs their attention.

### 2. Responsiveness should be considered from the start

Effective responsive design is more than shrinking a desktop interface. Content needs to be rearranged appropriately so the dashboard remains readable and usable on smaller screens.

### 3. Designing first reduces implementation ambiguity

Drafting the interface in Figma gives the team a way to discuss layout and user experience before writing code. This allows design decisions to be reviewed earlier and more clearly.

## Conclusion
